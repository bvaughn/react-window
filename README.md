<img src="https://react-window.vercel.app/og.png" alt="react-window logo" width="400" height="210" />

`react-window` is a component library that helps render large lists of data quickly and without the performance problems that often go along with rendering a lot of data. It's used in a lot of places, from React DevTools to the Replay browser.

### List

<!-- List:description:begin -->
Renders data with many rows.
<!-- List:description:end -->

#### Required props

<!-- List:required-props:begin -->

<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>rowComponent</td>
      <td><p>React component responsible for rendering a row.</p>
<p>This component will receive an <code>index</code> and <code>style</code> prop by default.
Additionally it will receive prop values passed to <code>rowProps</code>.</p>
<p>ℹ️ The prop types for this component are exported as <code>RowComponentProps</code></p>
</td>
    </tr>
    <tr>
      <td>rowCount</td>
      <td><p>Number of items to be rendered in the list.</p>
</td>
    </tr>
    <tr>
      <td>rowHeight</td>
      <td><p>Row height; the following formats are supported:</p>
<ul>
<li>number of pixels (number)</li>
<li>percentage of the list&#39;s current height (string)</li>
<li>function that returns the row height (in pixels) given an index and <code>rowProps</code></li>
<li>dynamic row height cache returned by the <code>useDynamicRowHeight</code> hook</li>
</ul>
<p>ℹ️ Percentage heights can&#39;t be resolved during server rendering unless a <code>defaultHeight</code> (or a pixel height via the <code>style</code> prop) is specified.</p>
<p>⚠️ Dynamic row heights are not as efficient as predetermined sizes.
It&#39;s recommended to provide your own height values if they can be determined ahead of time.</p>
</td>
    </tr>
    <tr>
      <td>rowProps</td>
      <td><p>Additional props to be passed to the row-rendering component.
List will automatically re-render rows when values in this object change.</p>
<p>⚠️ This object must not contain <code>ariaAttributes</code>, <code>index</code>, or <code>style</code> props.</p>
</td>
    </tr>
  </tbody>
</table>

<!-- List:required-props:end -->

#### Optional props

<!-- List:optional-props:begin -->

<table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>className</td>
      <td><p>CSS class name.</p>
</td>
    </tr>
    <tr>
      <td>style</td>
      <td><p>Optional CSS properties.
The list of rows will fill the height defined by this style.</p>
</td>
    </tr>
    <tr>
      <td>children</td>
      <td><p>Additional content to be rendered within the list (above rows).
This property can be used to render things like overlays or tooltips.</p>
</td>
    </tr>
    <tr>
      <td>defaultHeight</td>
      <td><p>Default height of list (in pixels) for initial render, before its actual height has been measured.</p>
<p>ℹ️ Lists can&#39;t be measured during server rendering, so this value determines how many rows are server rendered.
It&#39;s recommended to set this to the expected height of the list (or to specify a pixel height via the <code>style</code> prop).</p>
</td>
    </tr>
    <tr>
      <td>defaultScrollOffset</td>
      <td><p>Initial scroll offset (in pixels) of the list.
This value is only applied once, when the list first mounts with at least one row.</p>
<p>ℹ️ Server-rendered HTML can&#39;t be pre-scrolled, so server rendering always starts at the first row;
the default scroll offset is applied once the list hydrates.</p>
<p>⚠️ If the list can&#39;t be scrolled that far when the offset is applied (e.g. it is hidden with <code>display: none</code>,
or uses percentage row heights before its height has been measured), the offset is clamped or ignored and not retried.
Specify a <code>defaultHeight</code> (or a pixel height via the <code>style</code> prop) when using percentage row heights.</p>
</td>
    </tr>
    <tr>
      <td>listRef</td>
      <td><p>Ref used to interact with this component&#39;s imperative API.</p>
<p>This API has imperative methods for scrolling and a getter for the outermost DOM element.</p>
<p>ℹ️ The <code>useListRef</code> and <code>useListCallbackRef</code> hooks are exported for convenience in TypeScript projects.</p>
</td>
    </tr>
    <tr>
      <td>onResize</td>
      <td><p>Callback notified when the List&#39;s outermost HTMLElement resizes.
This may be used to (re)scroll a row into view.</p>
</td>
    </tr>
    <tr>
      <td>onRowsRendered</td>
      <td><p>Callback notified when the range of visible rows changes.</p>
</td>
    </tr>
    <tr>
      <td>overscanCount</td>
      <td><p>How many additional rows to render outside of the visible area.
This can reduce visual flickering near the edges of a list when scrolling.</p>
</td>
    </tr>
    <tr>
      <td>rowKey</td>
      <td><p>Lists use the row index as a <code>key</code> by default.
This prop can provide a custom <code>key</code> value.</p>
<p>ℹ️ Custom keys can ensure better UX for sortable or filterable lists,
particularly if your row components are stateful.
Refer to the <a href="https://react.dev/learn/rendering-lists#keeping-list-items-in-order-with-key">React documentation</a> for more info.</p>
<p>⚠️ This prop cannot be auto-memoized because it is called during render.
It is important to always <code>useCallback</code> for this prop; do not use an inline function.</p>
</td>
    </tr>
    <tr>
      <td>scrollElement</td>
      <td><p>Element that scrolls the list, for lists that scroll along with other content (e.g. the page):</p>
<ul>
<li>&quot;window&quot; to scroll with the page</li>
<li>an ancestor element that scrolls (e.g. stored with a <code>useState</code> ref callback); <code>null</code> until it has mounted</li>
</ul>
<p>The list renders at its full height and only renders the rows visible within the scroll element&#39;s viewport.
Its position within the scroll element is measured whenever it renders, scrolls, or resizes,
and whenever content before it is resized, inserted, or removed (e.g. an image loading above the list).</p>
<ul>
<li><code>scrollToRow</code> scrolls the scroll element</li>
<li><code>defaultHeight</code> is used as the viewport height until the scroll element has been measured (e.g. during server rendering)</li>
<li>percentage row heights are relative to the scroll element&#39;s viewport height</li>
<li><code>defaultScrollOffset</code> is ignored</li>
</ul>
<p>ℹ️ While the scroll element is <code>null</code>, the list renders the first rows (as it does during server rendering).</p>
<p>⚠️ The list itself doesn&#39;t scroll, so its <code>onScroll</code> handler isn&#39;t called;
listen to the scroll element&#39;s &quot;scroll&quot; events instead (or use the <code>useIsScrolling</code> hook).</p>
</td>
    </tr>
    <tr>
      <td>tagName</td>
      <td><p>Can be used to override the root HTML element rendered by the List component.
The default value is &quot;div&quot;, meaning that List renders an HTMLDivElement as its root.</p>
<p>⚠️ In most use cases the default ARIA roles are sufficient and this prop is not needed.</p>
</td>
    </tr>
  </tbody>
</table>
